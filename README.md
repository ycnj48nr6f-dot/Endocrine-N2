# Single-file GitHub Pages version

This is the same complete 320-question endocrine floor game, packed into `index.html` with its own CSS, JavaScript and image. It has no additional files or external dependencies. Create a public GitHub repository, upload **index.html**, and turn on Settings → Pages → Deploy from branch → main → /(root). Share the published Pages URL. Progress saves locally in each student's own browser. The original instructor PowerPoint is **not** embedded or published.
